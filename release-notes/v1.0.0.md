# StreamParser v1.0.0

首个正式版本。StreamParser 是一个基于 ASIO 的流式协议解析库：**库只负责“字节流 → 帧”和通信，协议由你写。**

## 亮点

- **零协议假设**：`sp::core` 不依赖任何第三方库，也不认识任何具体帧格式。
  你继承 `sp::StreamParser`，实现 `processByte()` 与 `buildFrame()`，
  粘包/拆包、帧超时、最大帧长保护、错误上报都由基类处理。
- **可插拔注入**：适配器和统一门面通过 `ParserFactory` 注入解析器，
  同一套传输代码可以配任何协议，业务层与 I/O 完全解耦。
- **统一传输门面**：`sp::Transport` + `CreateTransport()` 把 asio 关在门面内部，
  `tcp_server` / `tcp_client` / `udp` / `serial` 四种模式只差一个配置项。
- **可安装的 CMake 包**：`find_package(sp 1.0 CONFIG REQUIRED)`，
  链接 `sp::core` 或 `sp::transport`；ASIO 头文件随包安装（`sp::asio`），无需自行准备。
- **C++14，MIT**。

## 安装

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
      -DSP_BUILD_EXAMPLES=OFF -DSP_BUILD_TESTS=OFF
cmake --build build --config Release
cmake --install build --config Release --prefix /opt/streamparser
```

下游：

```cmake
find_package(sp 1.0 CONFIG REQUIRED)
add_executable(my_app main.cc)
target_link_libraries(my_app PRIVATE sp::transport)
```

## 内容

- `include/sp/`：解析器基类、日志回调接口、统一门面、串口/TCP/UDP 适配器
- `sp::core` / `sp::transport`：分层库，前者无第三方依赖
- `examples/`：五个示例程序，以及作为参考实现的两个示例解析器
  `A55A55AAParser.h`、`StartEndParser.h`（**不随安装包发布**，按需复制到自己的工程）
- `tests/`：基类与示例解析器的单元测试、日志冒烟、TCP 与门面 e2e、
  以及用 `find_package(sp)` 消费安装包的独立工程

## 兼容性

- 要求 C++14 编译器：GCC 5+ / Clang 3.4+ / MSVC 2015+
- 已在 Linux x64 / x86 / arm64 / armv7（qemu）、Windows x64 / arm64 上验证
- 与 pipeforge、xec 等其它项目无耦合，可独立使用
